## Full checkup
When asked to do full checkup, examine the while codebase,
and suggest improvements
* High level problems
    * Unreadable/unmaintainable code
    * Unused or outdated libs
    * Custom code that could be replaced by lib
* Code quality + performance
    * Unnecessary db calls etc
    * Duplicated / dead code
    * Refactoring / Simplification / Cleanup to do
* Formatting: imports, indents, etc
* Docs up to date
* Easy wins / Improvements?
